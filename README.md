# 방과후 곳간 🧮

방과후학교 강사비 예산의 잔여 소요를 자동 계산해, 추경 시 **반납(감액)·증액 예상액**을 바로 알려주는 웹 서비스입니다.

핵심 산식: `추경 예상액 Δ = (기정예산 − 집행액) − Σ강좌별[남은 수업 횟수 × 시수 × 단가 + 출강일수 × 교통비]`

## 주요 기능

- **절차형 설정**: 학교 정보 → 예산 → 강좌 → 휴강일·방학 → 확인
- **강좌 일괄 등록**: 학기중 / 여름방학 / 겨울방학 구분, 요일·시수·단가·교통비
- **휴강일 목록 입력**: 법정 공휴일 자동 반영(개별 해제 가능), 보강일 처리
- **세출예산 엑셀 가져오기**: K-에듀파인 세출예산집행현황을 올려 산출내역을 체크·유목화(강사비/교통비/재료비/기타)
- **운영계획서(hwpx) 가져오기**: 시간표(격자형·목록형)를 읽어 강좌 목록을 신규/변경/폐강 후보로 현행화
- **산출내역별 추경 예상 + 예산 활용 가이드**: 월별 지급 예정표, 규칙 기반 조언
- **보고서**: 결재 첨부용 A4 인쇄 뷰 + CSV 다운로드

데이터는 전부 **브라우저 localStorage에만** 저장됩니다 (서버 전송 없음). 백업은 설정 탭에서 JSON으로.

## 개발

```bash
npm install
npm run dev        # 개발 서버
npm test           # 계산 코어 테스트
npm run typecheck  # 타입 검사
npm run build      # dist/ 정적 빌드
```

기술 스택: React + TypeScript + Vite. 계산 로직은 `src/core/`의 순수 함수로 분리되어 있고 vitest로 검증합니다.

### fixtures (저장소 미포함)

`fixtures/` 폴더의 파서 검증용 실물 파일(세출예산집행현황.xls, 운영계획서.hwpx)은 실제 학교 데이터가 들어 있어 git에서 제외됩니다. 해당 파일이 없으면 `eduimport.test.ts`, `hwpximport.test.ts`가 실패하며, 같은 형식의 파일을 넣으면 통과합니다.

### URL 파라미터

- `?sample` — 예시 데이터로 시작 (시연용)
- `?setup` — 설정 절차 강제 진입
- `?tab=courses|closed|report|settings` — 특정 탭으로 열기

## 배포

`npm run build` 결과물(`dist/`)을 Vercel, Cloudflare Pages 등 정적 호스팅에 올리면 됩니다.
